# freepbx-korean-alarm

> **한국어 음성 알림·모닝콜 시스템 for FreePBX 17 / Asterisk**
> Korean-voice wake-up & time-announcement calling for FreePBX 17.
> 내선 **7000** 하나로 몇 분 뒤·시각·요일 반복 예약, 콜백 방식 수신 화면 표시.
> 음성은 조각 합성이라 **지연·비용·인터넷 0**.

## 한눈에 보는 흐름

```
                 ┌───────────────────────────────────┐
   7000 ────────▶│  "안녕하세요. 시간 알림 써비스입니다."  │   (콜백으로 수신)
                 └─────────────────┬─────────────────┘
                                   │
     메뉴를 한 항목씩 읽어 주며 화면을 넘깁니다 (안내 도중 눌러도 됨)
                                   │
     ┌──────────────┬─────────────┼──────────────────┐
   1 몇분후       2 시간        3 반복             4 목록
   분만 누름    4자리(24h)   평일/주말/           한 건씩
     30           1300      요일별/매일       [1]수정 [2]삭제 [9]다음
     │              │            │                    │
     └──────────────┴────────────┘               끝나면 홈으로
                    │
        예약을 잡고 → 들려주고 → 틀리면 [0]번 수정
```

**셋(몇분후·시각·반복)은 입력만 다르고, 확인부터는 같은 코드(`wk-lib`)를 씁니다.**
그래서 늘려도 복잡해지지 않습니다.

먼저 **예약을 잡고 나서** 들려줍니다. 맞으면 손이 한 번도 더 안 가고,
틀렸을 때만 `0`번을 눌러 방금 잡은 것을 지우고 다시 입력합니다.

## 입력 규칙

| 메뉴 | 누르는 것 | 예 | 결과 |
|---|---|---|---|
| **1번** 몇 분 뒤 | 분만 (예 `30`) | `30` | 삼십 분 뒤 |
| **2번** 시간 | 네 자리 (24시간제) | `1300` | 오후 한 시 |
| **3번** 반복 | 평일/주말/요일별/매일 → 시간 | `1` `0730` | 평일 오전 일곱 시 반 |
| **4번** 목록 | 한 건씩 듣고 [1]수정 [2]삭제 [9]다음 | `2` | 그 예약 삭제 |

**안내 도중 미리 눌러도 됩니다.** 메뉴를 끝까지 안 듣고 아는 번호를 바로 눌러도
잡힙니다(barge-in). **우물 정자(`#`)도 안 눌러도 됩니다** — 숫자만 누르고 손을
떼면 5초 뒤에 넘어갑니다. 예약 확인 뒤 **수정(0번) 대기만 3초**로 짧습니다
(그냥 두면 확정되기 때문). 발화 뒤에는 **0.5초 쉬고** 끊어 뚝 끊기지 않습니다.

시각 안내는 **짧은 것 먼저, 못 알아들으면 자세한 것**을 냅니다.
9.3초 → (두 번째 시도) 17.7초. 매번 긴 설명을 다 듣게 하지 않습니다.

시각(2번)은 **24시간제**입니다. 오후는 열두 시간을 더해 누릅니다
(저녁 일곱 시 = `1900`, 밤 열 시 = `2200`). 두 번째 안내에서 이 예시를
자세히 들려줍니다.

반복(3번)은 **두 단계**입니다. 먼저 **평일 `1` / 주말 `2` / 요일별 `3` / 매일 `4`**
중 하나를 고르고, 이어서 시각을 누릅니다. "평일/주말"을 한 줄에 몰아 읽지 않고
**"평일 반복은 일번"처럼 또박또박** 말해 잘 들립니다.

**요일별(`3`)** 로 들어가면 **화면에 두 개씩 보여 주며 넘깁니다**
(`[1]월요일[2]화요일` → `[3]수요일[4]목요일` → … → `[7]일요일[9]매일`).
**하루만** 고르고(안내 도중 눌러도 됨), 여러 요일이 필요하면 **여러 번 예약**하면
됩니다. **매일**은 여기 `9`번 또는 위 메뉴 `4`번.

반복을 등록하면 **첫 알림이 언제인지** 알려 줍니다.

```
"평일 / 오전 일곱 시 삼십 분 알람 설정하였습니다.
 내일부터 시작합니다."
```

## 파일이 하는 일

| 파일 | 하는 일 |
|---|---|
| `wakeup.agi` | **여기 하나에 전부 있습니다.** 시각→한국어 변환, 예약, 목록, 삭제 |
| `extensions_custom-korean.conf` | 메뉴와 흐름. AGI 가 준 재생 목록을 틀기만 합니다 |
| `make-korean-sounds.py` | 안내 음성 조각 163개를 8kHz·16kHz 두 벌로 만듭니다 |
| `wk-daily.py` | 반복 규칙을 매일 그날치 call file 로 펼칩니다 |
| `wakeup-daily.timer` | 위를 매일 00:05 + 부팅 2분 뒤 실행 |
| `replace-blocks.py` | 옛 다이얼플랜을 표시 구간째 교체 (여러 번 돌려도 안 쌓임) |
| `wakeup-prune.service` | 부팅 때 asterisk 보다 먼저 지난 call file 청소 |
| `wakeup-logrotate` | `wakeup.log` 가 무한정 커지지 않게 |

## 전화기 화면 표시

말로만 들으면 놓칩니다. 단계마다 화면에 한 줄 띄웁니다.

```
7000 걸면(콜백 옴)  시간 알림 서비스
메뉴(한 항목씩)     [1]몇분뒤 알림 → [2]시각 알림 → [3]반복 알림 → [4]목록 확인
분 입력             몇 분 뒤 (예)30분 > 30
시간 입력           시간 (예)07:30 > 0730   ← 음성 예시와 동일
반복(한 항목씩)     [1]평일 → [2]주말 → [3]요일별 → [4]매일 ← 화면 넘김
요일별(2개씩)       [1]월요일[2]화요일 … [7]일요일[9]매일   ← 두 개씩 넘김
확인                오늘 오전 7:40[0]수정
목록(한 건씩)       평일07:00[1]수정[2]삭제   (다음은 잠시 기다림, 끝나면 홈)
시간 알림 올 때(벨) 시간 알림
받은 뒤             지금 23:00                    ← 현재 시각만
```

기종에 따라 통화 중 화면이 안 바뀔 수 있습니다. 그때는
`wk-lib,disp` 첫 줄의 `WK_NODISP` 를 `1` 로 바꾸면 **한 줄로 전부 꺼집니다.**
음성 안내는 그대로라 손해는 없습니다.

## 발신 화면이 안 뜨면 — 콜백으로 받습니다

**내가 7000 을 거는 발신 통화**는 내 전화기가 '발신자'라, 통화 중 화면
갱신이 안 되는 기종이 있습니다(모임스톤 등). 반면 **걸려온 전화(수신)**는
발신자 이름이 확실히 뜹니다(알람이 잘 보이는 이유).

그래서 7000 을 걸면 **받고 → 1초 뒤 끊고**, 시스템이 그 내선으로
**되걸어(콜백)** 수신으로 메뉴를 진행합니다. 화면(발신자 이름)이 제대로 뜹니다.
(0초에 뚝 끊기면 이상해서 한 박자를 둡니다.)

```
7000 발신 → 1초 뒤 끊김 → 1초 뒤 내 내선으로 콜백 → (자동응답) → 띵동 벨 → 메뉴 (화면 정상)
```

- 콜백을 받으면 맨 앞에 **띵동 알림벨**이 한 번 울려서 "지금 왔구나"를
  바로 알 수 있습니다.
- **아무 키도 안 누르면 1분 뒤 딱 한 번 더 콜백**합니다. 콜백 때 키 입력을
  약 10초 기다리고, 안 누르면 "입력이 없어 잠시 후에 다시 걸어 드리겠습니다"
  라고 안내한 뒤 재콜백을 예약합니다. 두 번째(재)콜백에서도 무입력이면
  더는 걸지 않고 끝냅니다. 재콜백 간격은 `WK_CB_RETRY_DELAY`(기본 60초).
- **자동 응답은 전화기 자체 설정(Auto Answer)에 맡깁니다** — SIP 헤더를 안
  붙입니다. 모임스톤 등 전화기에서 자동응답을 켜 두면 저절로 받아집니다.
  (안 켜면 그냥 벨이 울리고, 받으면 메뉴가 나옵니다.)
- 콜백을 끄고 예전처럼 바로 메뉴로 가려면 다이얼플랜에서 `WK_NOCB=1`.
- 콜백 지연은 기본 1초(0초는 너무 급함). 앞 통화가 채 안 끊겨 잠깐 통화중이면
  3초 뒤 한 번 재시도합니다. 지연을 바꾸려면 `WK_CB_DELAY`.
- 외부·트렁크처럼 내선이 아닌 발신은 콜백하지 않고 바로 메뉴로 갑니다.

## 실수와 사고를 막는 장치

| 상황 | 어떻게 되나 |
|---|---|
| 같은 시각을 두 번 예약 | "이미 예약되어 있습니다" — 두 번 울리지 않습니다 |
| 같은 반복을 두 번 등록 | 마찬가지로 막습니다 |
| 동시에 등록/삭제 | 모든 경로가 같은 파일 잠금을 씁니다 (8건 동시 삭제 시험 통과) |
| 규칙 파일이 깨짐 | **아무것도 지우지 않고** 실패합니다. 빈 파일로 오인해 전부 날리지 않습니다 |
| 예약이 9개를 넘음 | 확인 듣기 **전에** "가득 찼습니다" — 상한을 목록 번호와 맞췄습니다 |
| 안내 도중 알람 하나가 울려 사라짐 | 번호가 아니라 스냅샷 키로 지우므로 엉뚱한 걸 지우지 않습니다 |
| 서버가 꺼졌다 켜짐 | 지난 call file 을 asterisk 보다 먼저 청소 (밀린 알람이 한꺼번에 울리지 않습니다) |
| AGI 가 실행 실패 | 빈 재생 목록을 막아 무음 종료 대신 "오류가 발생했습니다" |
| 요일에 `01` 같은 오입력 | 조용히 월요일로 바꾸지 않고 오입력으로 처리 |
| 안내 음성이 하나 사라짐 | `wk-daily.py --check` 로 찾아냅니다 |
| 규칙 백업 | 하루 한 벌 `rules.bak.json` |
| 입력을 잘못함 | **다시 물어봅니다.** (예전엔 "다시 입력해 주세요" 하고 끊겼습니다) |
| 가만히 있음 | "입력이 없습니다" — 오입력과 다른 안내로 구분 |
| 확인 단계에서 머뭇거림 | 처음부터 다시 묻지 않고 확인만 한 번 더 들려줍니다 |
| 잘못 들어옴 | 어느 단계에서든 `*` 를 누르면 처음 메뉴로 |
| 목록을 끝까지 봄 | 끊지 않고 처음 홈 메뉴로 돌아갑니다 |
| 예약이 가득 참 | 끊지 않고 목록으로 데려다 줍니다 |

**규칙을 고칠 일이 생기면 `wakeup.agi` 만 보면 됩니다.** 다이얼플랜에는
한국어 지식이 하나도 들어 있지 않습니다. 예전에는 양쪽에 나뉘어 있어서
한쪽만 고치면 조용히 어긋났습니다.

## 왜 조각을 미리 만들어 두나

통화 중에 TTS 를 호출하면 1~3초 멈춥니다. 우리가 말할 문장은 종류가
정해져 있으니 조각으로 쪼개서 미리 만들어 두고 이어 재생합니다.
Asterisk 가 원래 숫자를 읽는 방식(`digits/1`, `digits/2` …)과 같습니다.

```
오전 + 일곱시 + 사십분 + 알람 설정하였습니다  …
현재 시각은 + 오전 + 일곱시 + 사십분 + 입니다
```

조각 163개로 **1440가지 시각 × 1440가지 소요시간 × 127가지 요일조합**을
전부 만들 수 있습니다. 지연 0, 비용 0, 인터넷 0.

## 반복은 왜 규칙 파일로 하나

call file 은 한 번 쓰면 사라집니다. "알람이 울릴 때 다음 주 것을 예약"
하는 방식은 한 번이라도 실패하면 사슬이 끊깁니다.

규칙만 `/var/lib/asterisk/wakeup/rules.json` 에 두고, 타이머가 매일
그날 것만 펼칩니다. 서버가 며칠 꺼져 있어도 켜지면 스스로 따라잡습니다.

```bash
sudo wk-daily.py --list      # 등록된 반복 알림
sudo wk-daily.py --del 3     # 3번 규칙 삭제
sudo wk-daily.py --dry       # 오늘 뭐가 깔릴지 미리보기
sudo wk-daily.py --check     # 안내 음성 조각이 다 있는지 검사
sudo wk-daily.py --prune     # 지난 call file 청소
systemctl list-timers wakeup-daily.timer
```

## 한국어에서 신경 쓴 것

| | 틀린 말 | 바른 말 |
|---|---|---|
| 정오 조사 | 정오**으로** 예약했습니다 | (꼬리말을 "알람 설정하였습니다"로 바꿔 조사 자체를 없앰) |
| 자정/정오 | 오전 열두시 정각 | **자정** |
| | 오후 열두시 정각 | **정오** |
| 시간대 | 오전 세시 삼십분 | **새벽** 세시 삼십분 |
| | 오후 일곱시 삼십분 | **저녁** 일곱시 삼십분 |
| | 오후 열시 십오분 | **밤** 열시 십오분 |
| 반복 | 일곱시 삼십분**마다** (30분 간격으로 들림) | 일곱시 삼십분**에 알림이 울립니다** |
| 30분 | 일곱 시 **삼십 분** | 일곱 시 **반** (소요시간은 그대로 "삼십 분 후에") |
| 발음 | 서**비스** (전화 음질에 '서'가 흐림) | **써비스** (된소리로 또렷하게) |

조사는 마지막 글자의 받침을 계산해서 `으로`/`로`를 고릅니다.

## 예약 시각에 걸려오는 전화 (시간 알림)

정한 시각이 되면 전화가 걸려와 **현재 시각을 알려 줍니다.**

```
(벨)  화면: 시간 알림
(받은 뒤) 화면: 지금 07:40                     ← 현재 시각만
     "안녕하세요. 시간 알림 써비스입니다. 현재 시각은 오전 일곱 시 사십 분입니다."
     "좋은 하루 되세요."
```

1분 울리고 안 받으면 30초 뒤 재시도, 최대 3번(처음 1번 + 2번 더)입니다.
바꾸려면 `wakeup.agi` 위쪽 세 줄만 고치세요.

```python
RING_SEC = int(os.getenv("WK_RING_SEC", "60"))    # 1분 울림
MAX_RETRY = int(os.getenv("WK_MAX_RETRY", "2"))   # 안 받으면 2번 더
RETRY_SEC = int(os.getenv("WK_RETRY_SEC", "30"))  # 30초 뒤 재시도
```

> 60초를 다 울리려면 FreePBX 내선의 **Ring Time** 이 60 이상이어야 합니다.
> 기본값이 20초면 그쪽이 먼저 끊습니다.

## 전화기 화면이 안 뜰 때

두 가지가 다 맞아야 뜹니다.

1. **엔드포인트가 헤더를 보내야 합니다.** `send_rpid` / `send_pai` 기본값이
   `no` 라 Asterisk 가 이름을 바꿔도 SIP 로 나가는 게 없습니다.
2. **`CONNECTEDLINE(pres)` 가 `allowed` 여야 합니다.** 기본값이
   `unavailable` 이라 그대로 두면 `send_pai=yes` 를 켜도 "표시할 수 없는
   정보"로 보고 헤더를 안 만듭니다. → 다이얼플랜에 넣어 두었습니다.

1번은 스크립트로 한 번에 켭니다. 공통 블록 하나에 내선마다 한 줄입니다.

```bash
sudo ./enable-display.sh --all      # 모든 내선
sudo ./enable-display.sh --show     # 상태 보기
sudo ./enable-display.sh --off      # 되돌리기
```

```
[wk-display](!)            <- 공통 설정. 여기만 고치면 전부 반영
send_rpid=yes
send_pai=yes
trust_id_outbound=yes
send_connected_line=yes
connected_line_method=invite

[1001](+,wk-display)       <- 내선은 한 줄씩
[1002](+,wk-display)
```

`pjsip.endpoint.conf` 는 Apply Config 때마다 FreePBX 가 다시 만들므로
직접 고치면 사라집니다. 그래서 `pjsip.endpoint_custom_post.conf` 에 씁니다.
트렁크(이름이 숫자가 아닌 것)는 발신자 이름이 통신사로 새어 나가지 않게
일부러 제외합니다.

```bash
sudo tee /etc/korean-voice.env >/dev/null <<'EOF'
OPENAI_API_KEY=sk-...
```

그다음 웹에서:

- Applications → Misc Applications → Feature Code `7000`
- Apply Config

**번호는 7000 하나뿐입니다.** 확인·삭제는 메뉴 4번으로 들어갑니다.

기본 목소리는 `cedar`(공식 문서 기준 최고 품질), 말 속도는 평소의 90%입니다.
바꾸려면 `--voice marin` 처럼 주거나 `make-korean-sounds.py` 의
`TTS_INSTRUCTIONS` 에서 퍼센트를 조정하세요.
(alloy ash ballad coral echo fable nova onyx sage shimmer verse marin cedar)

### 안내 문구를 고쳤을 때 (음성 다시 만들기)

`make-korean-sounds.py` 의 문구(`GREETINGS`)나 `TTS_INSTRUCTIONS` 를 바꾸면
해당 조각을 다시 합성해야 반영됩니다. 스크립트는 이미 있는 파일은 건너뛰므로,
**바꾼 조각만 지우고** 다시 돌리면 그것만 새로 만듭니다.

```bash
cd /var/lib/asterisk/sounds/custom/bank
# 바꾼 조각의 .wav 와 .wav16 을 지웁니다 (예: 메뉴 1·2번과 인사)
sudo rm -f g-menu-1.wav g-menu-1.wav16 g-menu-2.wav g-menu-2.wav16 \
           g-intro.wav g-intro.wav16
sudo TTS=openai /opt/korean-voice/venv/bin/python \
     /usr/local/bin/make-korean-sounds.py
```

`TTS_INSTRUCTIONS`(말투·속도)나 음량 정규화 방식처럼 **모든 조각에
영향을 주는 것**을 바꿨다면 전부 다시 만들어야 하므로 `--force` 를 붙입니다.

```bash
sudo TTS=openai /opt/korean-voice/venv/bin/python \
     /usr/local/bin/make-korean-sounds.py --force
```

## 나중에 날씨·버스를 붙일 때

조각 방식은 **정해진 말**에만 씁니다. 날씨나 버스 도착처럼 문장이 매번
다른 것은 그때그때 TTS 를 불러야 합니다. 지연은 알람 안내를 재생하는
동안 뒤에서 만들면 사라집니다.

다이얼플랜에서 `System()` 에 `&` 를 직접 쓰면 동작하지 않습니다
(`APPERROR`). `setsid` 로 떼어내는 한 줄짜리 래퍼를 거쳐야 합니다.
